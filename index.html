RAPONG이란?

RAPONG은 Claude AI를 기반으로 한 완전 자율 모의해킹 플랫폼입니다. 사용자의 개입 없이 정찰부터 데이터 유출까지 전체 공격 사이클을 자동으로 수행합니다.

77개의 MCP Tools를 제공하며, 이 중 68개가 31337 모드에서 자동으로 트리거됩니다. 나머지 9개는 평가(assessment) 관리 도구로, 수동으로 사용됩니다.

31337 모드를 활성화하면 무한 루프가 시작되며, 8단계 공격 사이클(정찰 → 매핑 → 취약점 평가 → 익스플로잇 → 사후 공격 → 측면 이동 → 권한 상승 → 데이터 유출)을 명시적인 중지 명령("그만", "멈춰", "정지", "스톱", "중단")이 있을 때까지 반복합니다.

🛠️ 77개 MCP Tools

모든 도구는 MCP (Model Context Protocol)을 통해 Claude AI와 연결됩니다

MCP Tools는 Claude AI가 실제 해킹 작업을 수행하기 위해 호출하는 함수들입니다. 총 77개의 도구가 있으며, 3개 카테고리로 나뉩니다:

  • Core Tools (35개): 기본 평가 관리, 네트워크 스캔, 취약점 테스트, 익스플로잇 실행 도구
  • Enhanced Tools (25개): 고급 공격 자동화, WAF 우회, 자동 체이닝, 클라우드 익스플로잇
  • Advanced Tools (17개): NoSQL 공격, API 퍼징, 폴리글랏 페이로드, 취약점 체인 그래프

이 중 68개가 31337 모드에서 자동으로 트리거되며, 9개 도구(assessment 관리, list 등)는 수동 사용 도구입니다.

8단계 공격 사이클 각 단계마다 해당하는 도구들이 자동으로 실행됩니다. 정찰 단계에서는 서브도메인 열거, 포트 스캔, 기술 탐지가 자동으로 돌아가고, 익스플로잇 단계에서는 SQLi, XSS, SSRF 등 모든 공격이 자동으로 시도됩니다.

🔗 2. Intelligent Chaining

각 단계의 결과가 다음 단계의 입력으로 자동 연결됩니다. SQLi로 DB 크레덴셜을 얻으면 자동으로 SSH에 시도하고, SSH 접근이 성공하면 즉시 권한 상승 스캐너가 실행되며, Root를 획득하면 자동으로 지속성 확보와 데이터 유출이 진행됩니다.

🧠 3. Context-Aware Selection

타겟의 기술 스택을 파악하여 불필요한 공격을 건너뜁니다. Laravel을 탐지하면 Laravel 특화 공격만 실행하고, MongoDB를 발견하면 NoSQL 인젝션으로 집중하며, IP 카메라를 식별하면 RTSP/ONVIF 공격으로 전환합니다. 시간 낭비 최소화, 효율 최대화.

♾️ 4. Never-Stop Protocol

31337 모드는 절대 멈추지 않습니다. 8단계를 완료하면 다시 1단계부터 시작하는 무한 루프. 첫 번째 사이클에서 못 찾은 취약점을 두 번째 사이클에서 발견하고, 새로 추가된 엔드포인트를 세 번째 사이클에서 공격합니다. 중지 명령 5개("그만", "멈춰", "정지", "스톱", "중단")만 인식하며 그 외엔 절대 안 멈춤.

🛡️ 5. Auto-Evasion

WAF, Rate Limit, 밴(Ban) 감지 시 즉각 대응합니다. 403 에러 → 자동으로 10가지 인코딩 시도, 429 에러 → IP 로테이션 + Exponential backoff, 밴 감지 → Tor exit node 변경 + User-Agent 변경. 인간보다 빠르고 집요한 회피.

📚 6. Learning & Adaptation

성공한 공격 패턴을 학습하여 데이터베이스에 저장합니다. "admin123"이 성공하면 "admin456", "admin789"를 자동 생성하고, Laravel Mass Assignment가 통했다면 다음 Laravel 타겟에서 우선 시도하며, 특정 WAF 우회 방법이 효과적이었다면 그 패턴을 재사용합니다. 공격할수록 똑똑해지는 AI.
