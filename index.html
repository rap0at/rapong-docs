1️⃣ Base 31337 Engine (27개 기능)

핵심 자율 모의해킹 능력 - 31337 모드의 기반

  • 1. Tor 익명화
    31337 트리거 시 Tor 자동 활성화. 모든 트래픽이 Tor 네트워크를 통해 라우팅되어 IP 추적 불가.
  • 2. IP 로테이션
    10개 요청마다 Tor exit node 자동 변경. 429 (Rate Limit) 감지 시 즉시 IP 변경.
  • 3. User-Agent 로테이션
    요청마다 UA 랜덤 변경 (Chrome, Firefox, Safari, Googlebot 등). 핑거프린팅 방지.
  • 4. WAF 자동 우회
    WAF 감지 시 10+ 인코딩 방법 자동 순환: URL, Unicode, Hex, Double, Comment Injection, Case Variation, Parameter Pollution, Null Byte 등.
  • 5. Rate Limit 감지
    429 응답, "rate limit" 문자열, Captcha 챌린지 자동 감지. 즉시 대응 로직 실행.
  • 6. 지수 백오프
    Rate limit 시 2, 4, 8, 16, 32초 간격으로 재시도. Jitter 추가로 thundering herd 방지.
  • 7. Ban 복구
    IP ban 감지 시 IP 로테이션 + UA 변경 + 5초 대기 후 자동 재시도. 3회 실패 시 VPN으로 전환.
  • 8. 무한 공격 루프
    8-Phase 사이클 무한 반복: Recon → Mapping → Vuln Assessment → Exploitation → Post-Exploit → Privesc → Lateral Movement → Exfiltration. "그만", "멈춰", "정지", "스톱", "중단" 중 하나 입력 전까지 영원히 실행.
  • 9. 도구 자동 다운로드
    필요한 wordlist, exploit, payload 자동 다운로드. SecLists, PayloadsAllTheThings, Exploit-DB 등에서 자동 fetch.
  • 10. 동적 도구 전환
    도구 실패 시 자동 전환: ffuf 실패 → gobuster → dirb → feroxbuster. 성공할 때까지 순환.
  • 11. 최대 병렬 실행
    9개 동시 공격 스레드. nmap, sqlmap, ffuf, nuclei 등을 동시에 실행. 순차 실행 대비 10배 빠름.
  • 12. Kill Chain 체이닝
    SQLi 발견 → DB 크레덴셜 추출 → SSH 시도 → 성공 → Privesc 스캐너 자동 실행 → Root 획득 → Persistence 자동 설정. 전 과정 자동화.
  • 13. 자기 비판 루프
    공격 실패 시 원인 분석 → 대안 생성 → 재설계 → 즉시 재시도. 같은 실수 반복 안 함.
  • 14. 모듈 자동 실행
    특정 조건 감지 시 관련 모듈 자동 실행. Shell 획득 → privesc_linux() 자동 실행. .git 발견 → shannon_whitebox_scan() 자동 실행.
  • 15. 증거 로깅
    모든 액션을 timestamp, command, output, SHA256 해시, CVSS vector와 함께 자동 기록. 법적 증거로 사용 가능한 chain-of-custody 보장.
  • 16. 네트워크 속도 감지
    응답 시간 모니터링. < 500ms → 딜레이 없음. 500ms-2s → 200ms 딜레이. 2s-5s → 1s 딜레이. > 5s → 3s 딜레이. 자동 적응.
  • 17. Context-Aware 공격
    Laravel 감지 → Laravel 전용 공격만 실행. MongoDB 발견 → NoSQL injection 집중. 10배 시간 절약.
